# Support

How to get help with this project.

## Documentation first

Start with:

- [`README.md`](README.md) — what the lab is.
- [`docs/install/README.md`](docs/install/README.md) — ordered install guide.
- [`docs/install/presenting.md`](docs/install/presenting.md) — normal demo operation.
- [`docs/install/troubleshooting.md`](docs/install/troubleshooting.md) — known failure signs and checks.
- Per-app `README.md` files for development commands.

## Reporting bugs

Open a bug report with:

- the version or commit hash;
- which app or install step is affected;
- the smallest reproduction steps;
- expected and actual behaviour;
- logs or screenshots if relevant;
- the AI path involved: MCS, Foundry, or both.

Do not include secrets, tokens, tenant-private IDs, or connection strings.

## Asking questions

Use the repository's normal issue or discussion process. This is a demonstration project, not a supported Microsoft product. For product support for Azure, Copilot Studio, Foundry, Intune, or Windows 365, use the official support channel for your tenant.
