# Contributing

Thank you for improving this lab.

## Start with the install docs

The supported setup is documented in [`docs/install/README.md`](docs/install/README.md). Keep changes aligned with that guide.

## Rules

- Do not commit secrets, tenant IDs, tokens, keys, connection strings, or filled-in `*.local.json` files.
- Do not push unless the repository owner explicitly asks you to.
- Keep documentation plain, ordered, and suitable for a reader with limited developer experience.
- Prefer small commits that each explain one change.
- Run the smallest useful validation before committing.

## Pull requests

Include:

- what changed;
- why it changed;
- how you validated it;
- any manual tenant step that remains.
